# Reinos de Etheria — MMORPG Pixel V1

V1 jugable en navegador, preparada como base para evolucionar a multiplayer y Telegram Mini App.

## Ejecutar
La forma más sencilla es abrir `client/index.html` en un navegador.

Para GitHub Pages:
1. Sube todo el proyecto a un repositorio.
2. En Settings > Pages selecciona la rama principal y carpeta `/client`.
3. Abre la URL de Pages.

## Controles
- WASD / flechas: mover
- Espacio: atacar
- E: interactuar con NPC/cofre
- I: inventario
